# Eldris Homebrew Tap

Official Homebrew tap for software maintained by [Eldris Inc.](https://eldris.io).

## Quick Start

Install software directly from this tap:

```sh
brew install --cask eldris-io/tap/<cask-name>
```

Or add the tap first:

```sh
brew tap eldris-io/tap
```

---

## Available Casks

### MacDown SE

The Apple Silicon continuation of the classic native Markdown editor for macOS, featuring built-in Model Context Protocol (MCP) support.

```sh
brew install --cask eldris-io/tap/macdown-se
```

Or after adding the tap:

```sh
brew install --cask macdown-se
```

To update to future releases:

```sh
brew upgrade --cask macdown-se
```
